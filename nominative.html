Nominative Case

(Именительный падеж)

The Nominative Case asks the questions "кто?" (who?) and "что?" (what?)

The nominative case is thought to be the easiest among all the Russian cases. Regardless, you should know when this case will be used.

There are some changes to adjectives that you should know. Note that a noun is feminine if it ends with "a" or "я" or some cases of "ь". Unfortunately, there is no rule for these cases, so you will need to memorize them yourself. A noun is masculine if it ends with a consonant or in some cases of "ь". A noun is neutral if it ends with "e", "ё", or "o". See the image on the right to know when to conjugate, with what ending, and after what letters.

Now that you understand that, the nominative case has 12 instances of use. Note these down, they will be important to know. Each case has its own use. After learning multiple cases, it can be confusing to remember which case you should use.

When will you use the Nominative Case?

1.) When we name a person or a thing. Example:

"Это

Иван."

- This is

Ivan.

"Вот

театр."

- This is

the theatre.

In this case, the theatre is in nominative case. You are stating that the theatre is here with "вот", so the theatre is in nominative case.

In this case, "Андрей" is in nominative case. The sentence asks the question "кто?" to who is giving the book.
