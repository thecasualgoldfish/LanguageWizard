Preterite Tense (Completed Past)

The preterite tense is a very common tense in spanish, but it can also be complex. See the chart on the right to see how to conjugate.

What are some common uses of the preterite tense?

The most common uses of the preterite tense are

  • Specific Moment (or specific number of instances)
  • Action that interrupts
  • Focus on beginning or ending
  • Enclosed action (for certain amount of time)

You can easily remember this with the acronym 'SAFE'. But what does each one really mean?

Specific Moment

A completed action. Something done in the past that happened as a one-off instance, specifying when something happened, or when you say how many times the instance occured.

For example: "Me llamó ayer" (He called me yesterday) << The word "ayer" triggers the preterite tense. When specifying when something happened, you know it is a completed action, and a one-time occurence so you use the preterite tense.

For example: "Me llamó tres veces" (He called me three times) << The words "tres veces" trigger the preterite tense. When specifying how many times something happened, you use the preterite tense.

Action (interrupting)

The preterite tense is also used when talking about an action interrupting anither action in the past. Remember that the preterite tense used ONLY for the object that is interrupting.
For example: "Estaba caminando cuando el teléfono sonó" (I was walking when the phone rang) << Because the phone ringing was the action that caused the interruption, you will use the preterite tense.

Focus on beginning (or ending)

You use the preterite tense when talking about when something started or stopped.
For example: "Terminó a llover" (It stopped raining) Because the it stopped raining, you should use the preterite IF this is a one-off action.
For example: "Empezó a llover" (It started to rain) << Because you use the verb "empezar" (to begin), when describing something occuring as a one off you will use the preterite.
While it can be confusing, you are also able to use the verbs "empezar" and "terminar" in the imperfect. Remember you use the imperfect when describing habitual actions so when you say "Empezaba a llover a las ocho" you are describing something that always used to happen. "It always started to rain at eight", compared to "Empezó a llover a las ocho" (It started to rain at eight)

Enclosed action

An enclosed action is something that happened for a certain amount of time. You use the preterite tense when you specify for how long something in the past occured.
For example: "Él vivió en Madrid por quince años." (He lived in Madrid for fifteen years). Specifying the amount of time that he lived in Madrid triggers the preterite tense.

Irregular Verbs

Knowing the conjugations is most of the preterite tense, but there are still some irregular verbs you should know. These are the most common.

Ir/Ser

These verbs are common in spanish, so they are important to know. Thankfully, they follow the same conjugation pattern!
Yo: Fui
Tú: Fuiste
Él/Ella/Usted: Fue
Nosotros: Fuimos
Ellos/Ustedes: Fueron

Ver

Yo: Vi
Tú: Viste
Él/Ella/Usted: Vio
Ellos/Ustedes: Vieron
Nosotros: Vimos

Dar

Yo: Di
Tú: Diste
Él: Dio
Ellos/Ustedes: Dieron
Nosotros: Dimos

-IE present stem change in preterite

Some verbs in the present like "pensar" have an e > ie stem change. This causes some changes to occur in the preterite. Don't worry! It is easier than it sounds.

How it works

  • -AR and -ER verbs lose the stem change completely.
For example: the verb pensar in present tense "Él piensa" > in preterite tense it changes to "Él pensó". You conjugate it without paying any mind to the present tense stem change. This works for every ar and er verb ending!
  • -IR verbs have a special stem change.
On the verbs that change e -> ie in the present tense, the preterite tense changes e -> i. (IN 3RD PERSON ONLY)
This means that the e only goes to i in the ella/él/usted and ellos/ustedes forms.
For example: sentir -> sintió, sintieron OR preferir -> prefirió, prefirieron. Notice that even when the stem change occurs in the end of the word "preferir", there is still a stem change!
