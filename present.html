Present Tense

The present tense is the most common tense in spanish, thankfully, it can be pretty simple! See the chart on the right to see how to conjugate.

What are some common uses of the present tense?

The most common uses of the preterite tense are

  • Habits and routines
  • Universal Truths
  • Going on now
  • Scheduled / Near future

You can easily remember this with the acronym 'HUGS'. But what does each one really mean?

Habits and Routines

Actions you do regularly / habitually. If it helps, the uses are pretty much the same in Spanish as in English. When talking about your routines, you use the present tense.

For example: "Corro todos los dias" (I run everyday) Because running is something you do everyday / regularly you use the present tense. It doesn't have to happen everyday, you could still use the present tense when talking about something you do every Tuesday, for instance.

Universal Truths

You use the present tense when talking about something that is always true, or known to be true.
For example: "El sol sale por el este" (The sun rises in the east) << Because you are stating it as a fact, you use the present tense.

Going on now

You use the present tense when talking about something you are doing right in the moment.
For example: "Hablo contigo" (I am talking with you) Becuase you are currently speaking with the person, you use the present tense.

Scheduled / Near Future

You use the present tense when telling about something that will occur in the near future / something that has been scheduled.
For example: "Manana viajo a Madrid" (Tomorrow I travel to Madrid) Because you are doing this action in the near future, while stating what time you are planning to do it, you use the present tense.
Don't worry if it seems confusing at first, it does for almost everyone! Soon, you will be a master of the present tense. Remember that these uses are very similar to English!

Irregular Verbs

Knowing the conjugations is most of the present tense, but there are still some irregular verbs you should know. These are the most common.

Ir (To go)

Yo: Voy
Tú: Vas
Él/Ella/Usted: Va
Nosotros: Vamos
Ellos/Ustedes: Van

To be

Spanish has 2 verbs for "to be". This can be confusing at first, but they each have their own use cases. Once you learn these, it will be a walk in the park!

Ser (To be)

Ser is used to describe permanent characteristics. Nationality, permanent character/physical traits, relationship, occupation, date and time, possession, event location, what something is made of.
Yo: Soy
Tú: Eres
Él/Ella/Usted: Es
Ellos/Ustedes: Son
Nosotros: Somos

Estar (To be)

Estar is used when talking about temporary characteristics. Emotions, where someone/something is, physical condition / state, position and posture, and ongoing actions.
Yo: Estoy
Tú: Estas
Él/Ella/Usted: Esta
Ellos/Ustedes: Estan
Nosotros: Estamos

-IE present stem change in preterite

Some verbs in the present like "pensar" have an e > ie stem change. This causes some changes to occur in the preterite. Don't worry! It is easier than it sounds.

How it works

  • -AR and -ER verbs lose the stem change completely.
For example: the verb pensar in present tense "Él piensa" > in preterite tense it changes to "Él pensó". You conjugate it without paying any mind to the present tense stem change. This works for every ar and er verb ending!
  • -IR verbs have a special stem change.
On the verbs that change e -> ie in the present tense, the preterite tense changes e -> i. (IN 3RD PERSON ONLY)
This means that the e only goes to i in the ella/él/usted and ellos/ustedes forms.
For example: sentir -> sintió, sintieron OR preferir -> prefirió, prefirieron. Notice that even when the stem change occurs in the end of the word "preferir", there is still a stem change!
